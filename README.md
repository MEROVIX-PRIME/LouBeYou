# Lou Be You — интернет-магазин

Статический сайт: HTML, CSS и JavaScript без сборки. Загружается на Netlify перетаскиванием папки.

## Что уже работает

- Лендинг на главной, магазин, коллекции, корзина, страница о Lou
- Три языка: вьетнамский (по умолчанию), английский, русский — переключатель в шапке
- Корзина сохраняется в браузере и переживает перезагрузку страницы
- Карточка товара открывается на отдельной странице с полным описанием и пятью похожими товарами
- Плашка «много» при остатке от 50 штук, точное количество — если меньше
- Таблица размеров у всех футболок
- Заказ уходит на почту через Netlify Forms
- Адаптив под телефон и компьютер

## Три шага до запуска

### 1. Подключить прайс из Google Таблиц

Таблица уже подключена по `sheetId` в `assets/js/config.js`. Сайт читает лист `Лист1` при каждом открытии.

Где взять ссылку:
1. Открой таблицу с прайсом
2. **Файл → Поделиться → Опубликовать в интернете**
3. Выбери нужный лист, формат — **CSV**
4. Нажми **Опубликовать** и скопируй ссылку

Цены, названия, описания, изображения, остатки и коллекции меняются прямо из таблицы: правишь ячейку — после обновления страницы сайт показывает новое значение. Если таблица временно недоступна, сайт берёт товары из `assets/js/products.js`.

**Колонки таблицы.** Сайт понимает такие заголовки (регистр не важен):

| Колонка | Что в ней | Обязательна |
|---|---|---|
| `id` | артикул, например TS-001 | да |
| `category` | `tshirt` или `mug` | да |
| `collection` | id коллекции, например `music` | да |
| `image` | прямая ссылка на картинку | да |
| `цена` | базовая цена в долларах, только число | да |
| `курс USD/VND` / `курс USD/RUB` | курсы для переключения валюты; достаточно заполнить первую строку | да |
| `old price` | старая цена — покажет скидку | нет |
| `stock` | остаток штук | да |
| `sizes` | `S, M, L, XL` через запятую | для футболок |
| `colors` | `Cream, Black` через запятую | нет |
| `quote` | фраза Lou с принта | нет |
| `name vi` / `name en` / `name ru` | название на трёх языках | да |
| `desc vi` / `desc en` / `desc ru` | описание | нет |
| `material vi` / `material en` / `material ru` | состав и уход | нет |

Свои названия колонок можно дописать в `sheetColumns` в `config.js` — например, добавить `"цена"` рядом с `"price"`.

**Картинки из Google Drive.** Можно вставлять обычную ссылку вида `https://drive.google.com/file/d/.../view` — сайт сам преобразует её в изображение. Доступ к файлу должен быть «Всем, у кого есть ссылка».

### 2. Добавить шрифт

Положи файл шрифта Yoon SunShower в `assets/fonts/` под именем `YoonSunShower.woff2` (либо `.woff`, `.otf`, `.ttf`). Больше ничего делать не нужно. Пока файла нет, используется похожий рукописный шрифт Gaegu.

### 3. Загрузить на Netlify

1. Зайди на [app.netlify.com](https://app.netlify.com)
2. Перетащи всю папку сайта в окно **Add new site → Deploy manually**
3. Сайт откроется по адресу вида `имя.netlify.app`

**Чтобы заказы приходили на почту:** в панели Netlify открой **Site configuration → Forms → Form notifications → Add notification → Email notification** и укажи свой адрес. Форма `lou-order` появится в списке после первого деплоя.

## Что меняется где

| Что нужно поменять | Файл |
|---|---|
| Ссылка на таблицу, доставка, порог «много», Instagram, почта | `assets/js/config.js` |
| Тексты интерфейса на трёх языках | `assets/js/i18n.js` |
| Запасной каталог и список коллекций | `assets/js/products.js` |
| Цвета, шрифты, отступы | `assets/css/style.css` (блок `:root` вверху) |
| Тексты про доставку, возврат и вопросы | `about.html`, объект `COPY` |

## Добавить новую категорию

1. В таблице ставь товарам новое значение в колонке `category`, например `tote`
2. В `assets/js/i18n.js` добавь ключ `shop.tote` во все три языка
3. В `shop.html` в массив `CATS` добавь строку `{ id: "tote", key: "shop.tote" }`

Коллекции добавлять не нужно — сайт собирает их сам из колонки `collection`. Чтобы у новой коллекции было красивое название и картинка, добавь её в `LOU_COLLECTIONS` в `products.js`.

## Оплата

Платёжная система пока не подключена: заказ оформляется, письмо уходит, оплата подтверждается по телефону. Когда выберешь провайдера (VNPay, MoMo, ZaloPay или Stripe), подключение делается в `cart.html` — в обработчике `form.addEventListener("submit", ...)`, вместо вызова `done(id)` нужно будет перенаправить покупателя на страницу оплаты.

## Таблица размеров

Пока показывается встроенная таблица в сантиметрах. Чтобы поставить свою картинку: положи её в `assets/img/` и укажи имя файла в `config.js` → `sizeChartImage`, например `"size-chart.webp"`.
